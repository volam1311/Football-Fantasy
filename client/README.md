# Football Chatbot - React Client

A modern React frontend for the Football Chatbot API.

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:3000`

## Configuration

By default, the app connects to `http://localhost:8000` (your FastAPI backend).

To change the API URL, create a `.env` file:
```
VITE_API_URL=http://your-api-url:8000
```

## Features

- Modern, responsive UI
- Real-time chat interface
- Markdown support for formatted responses
- Loading indicators
- Smooth animations
- Mobile-friendly design
